# Accessibility

Lookout aims to make its web interface usable by people with disabilities.
The target is [WCAG 2.2 Level AA](https://www.w3.org/TR/WCAG22/).
Full conformance has not been assessed.

The interface includes a skip link, visible keyboard focus, and reduced-motion styles.
These features do not establish screen-reader or browser compatibility.
Linked provider websites are outside this statement's scope.

## Report a barrier

[Open an issue](https://github.com/openRuyi-Project/lookout/issues/new?template=bug_report.md)
with the page, the task you could not complete, and the expected result.
If available, include the Lookout version, browser, and assistive technology.
Remove private data from URLs, screenshots, and logs.

## Review interface changes

Check keyboard access and focus after filtering, pagination, and automatic updates.
Check zoom, narrow screens, and both color themes.
Give controls and status icons accessible names. Do not use color alone to convey status.
Record the checks performed and any remaining barriers in the pull request.
