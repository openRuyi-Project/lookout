# Security policy

## Supported versions

Security fixes target the latest non-prerelease version published in
[GitHub Releases](https://github.com/openRuyi-Project/lookout/releases).
Older versions do not receive separate security updates. Upgrade to a fixed
release when a security advisory requires it.

The `main` branch contains development changes. A commit on `main` is not a
production release. Reports about `main` are also welcome.

## Report a vulnerability

Use [Report a vulnerability](https://github.com/openRuyi-Project/lookout/security/advisories/new)
to send a private report. Do not put exploit details or credentials in a public issue.

Include:

- The affected version or commit and, if available, the image digest.
- Reproduction steps and the security impact.
- Relevant configuration and logs, with credentials and personal data removed.

Test only systems that you own or have permission to test.
A vulnerability that Lookout reports in a monitored package belongs to that
package's upstream project, unless the defect is in Lookout itself.

We coordinate fixes and disclosure through the private report. Published
advisories identify affected versions, fixed versions, and any required operator action.
